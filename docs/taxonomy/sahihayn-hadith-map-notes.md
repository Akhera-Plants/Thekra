# Sahihayn (Bukhari + Muslim) → Thekra taxonomy map — Notes

Companion to `sahihayn-hadith-map.tsv`. Scope: every Sahih al-Bukhari / Sahih Muslim quote in the DB that had **no** ACCEPTED `SinQuote`/`GoodDeedQuote` row and **no** `ImanBranchQuote` row at export time (8,401 quotes: 6,258 Bukhari, 2,143 Muslim). Already-linked quotes were not reviewed.

Each unlinked quote got exactly one row. `targets` is empty when the hadith is left UNASSIGNED (tafsir, maghazi/sira, manaqib, fiqh procedure, stories of prophets, creation, fitan, dreams, pure narrative — expected and intentional). Up to 2 targets per row; `high` only where the hadith speaks about the topic as its main point.

## Method / caveats

- Export: `ReferenceHadith` joined to `Quote` via `rawPayload->>'referenceHadithId'`; chapter context from `SectionItem`/`BookSection` (bab title + ancestor path). ~100 quotes have no section row (bab shown empty).
- Decisions were made quote by quote from the matn (first 400 chars) plus bab/kitab context. Bukhari repeats were handled by reading each occurrence and by a 4-gram overlap pass that flagged unassigned near-duplicates of assigned rows; those received the same decision.
- `high` is reserved for explicit commands/virtues/warnings on the topic; `low` marks fragments, mu'allaq pieces, repeats where the DB matn is truncated, or hadith where the topic is present but not the main point.
- Several DB matn fields are fragments (isnad tails, «بمثله», tarjama glosses); these were left unassigned unless the fragment itself carries the point.
- Read-only: nothing was written to the DB; no code or other docs changed.
