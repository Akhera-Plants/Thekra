# Thekra (تذكرة)

**Thekra** — from the Arabic word **تذكرة** ("reminder" / "a reminder that brings something to mind") — is an
on-demand Islamic reminder app. Instead of pushing random daily content, it answers a very specific moment of
need:

- **"I feel tempted to commit a sin."** The user picks the sin (or the feeling behind it), and the app returns
  Quran verses, authentic Hadith, and scholarly words that **discourage** that sin: its consequences, the harm
  it causes, and the way back.
- **"I want to do a good deed."** The user picks the deed, and the app returns content that **motivates and
  rewards** it: the virtue of the act, its reward, and the example of the Prophet ﷺ and the righteous.

The core idea is that the right reminder, at the exact moment of temptation or intention, is more valuable than
a feed of generic content.

## Status: Phase 1 — structure only

> **This phase ships the monorepo structure, tooling, and the database schema only.**
> There are no features yet: no controllers, no API endpoints, no DTOs, no React components or pages, and no
> content ingestion jobs. Everything outside `backend/prisma/schema.prisma` is either framework boilerplate
> generated by the official NestJS / Next.js CLIs, or a placeholder folder with a plan note.

## Setup

Requires Node.js >= 24, pnpm 11.7.0, and Docker (for the local database).

```bash
# 1. Install all workspace dependencies from the repo root
pnpm install

# 2. Start the local PostgreSQL instance
docker compose up -d db

# 3. Create the backend environment file from the template
cp backend/.env.example backend/.env

# 4. Generate the Prisma client
pnpm --filter backend exec prisma generate
```

Useful root scripts:

```bash
pnpm prisma:validate   # validate the Prisma schema
pnpm prisma:generate   # regenerate the Prisma client
pnpm dev:backend       # NestJS in watch mode
pnpm dev:frontend      # Next.js dev server
```

Once the database container is running and `backend/.env` exists, the first migration can be created with:

```bash
pnpm --filter backend exec prisma migrate dev --name init
```

No migration is committed in this phase.
